部署到 GitHub Pages

1

推送到仓库

把 spark-prompts 目录内容推到 GitHub 仓库（建议仓库名与站点一致）。

2

开启 Pages

Settings → Pages → Source 选 Deploy from a branch，分支 main，目录 /root。

3

自定义域名

根目录添加 CNAME 文件写入域名，DNS 配置 A/CNAME 指向 GitHub Pages。

4

扩展词库

编辑根目录 prompts.json，再运行 node tools/build-data.mjs 同步 file 回退包。
